## 故障模拟

均使用同一独立回放库，测试前后逐份 GET 比较完整草稿；库内始终只有上述两份记录。

| 场景 | 注入方式 | 实际结果 |
| --- | --- | --- |
| 模型失败 | 显式测试模型抛出 B GenerationError，并含不可回显的测试标记；不连接真实提供方 | 浏览器收到 502 / AI_GENERATION_FAILED，提示明确，原提供方异常文本未泄漏，回到输入区资料仍在，两稿完整对象不变 |
| 服务端总超时 | 模型模拟运行 7 秒，验收入口总预算设为 5 秒；生产默认仍为 45 秒 | 浏览器约 5.66 秒收到 504 / AI_TIMEOUT；确认慢任务 started=1、finished=1 后再查库，无新增、覆盖或迟到写入，输入保留 |
| 前端请求超时 | 在独立 5175 Vite 测试进程中设置原版支持的 VITE_TIMEOUT_MS=1000，仍连接上述慢任务服务 | 浏览器 net::ERR_ABORTED，页面显示“请求超时（1 秒）”；输入保留。等待该慢任务结束且服务端时限超出后，两稿仍不变 |

第三项验证的是缩短配置后的客户端超时分支，不是等满默认 60 秒的真实模型验收。浏览器主动断开不保证立即取消上游请求；迟到不落库的保证针对服务端总时限。本次短客户端超时场景中的服务端也超时了，不能推广成任意客户端断开都绝不保存。
